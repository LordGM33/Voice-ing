# Voice-ing

Repositorio companion del libro **Ingenieria de Voz para Avatares Autonomos** (Libro I de la serie
*Arquitectura de un Avatar Autonomo Basado en IA*).

Contiene los scripts del taller del libro: siguiendolos capitulo a capitulo, el lector construye
una version basica de un sistema de generacion y clonacion de voz (TTS con clonacion zero-shot,
normalizacion de texto, seleccion de referencia, QA y best-of-N).

Proyecto: https://twincastia.com

Estado: en preparacion junto con la edicion en curso del libro.
